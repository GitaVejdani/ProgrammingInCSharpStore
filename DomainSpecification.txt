سبد خرید:
هر مشتری یک سبد خرید دارد.
هر سبد خرید دارای یک سری آیتم است
مشتری می‌تواند به این سبد یک آیتم جدیداضافه ، آیتم موجود در سبد را حذف کند یا تعداد آیتم‌های موجود را کم و زیاد کند
وضعیت سبد خرید درصورتیکه مشتری در حال خریداست فعاله و اگر نهایی شده باشد تبدیل به یک سفارش می‌گردد

سفارش:
پس از نهایی شدن سبد خرید،مشتری به درگاه پرداخت متصل گردیده سپس نتیجه‌ی تراکنش بررسی و درصورت موفق بودن تراکنش زمان ارسال هماهنگ می‌گردد.

وضعیت سفارش:در انتظار پرداخت- پرداخت شده-کنسل -ارسال شده -تحویل داده شده

		- Address -> string
		- UserName -> string
		- Password(Hash) -> string
		
		+ Register
		+ Read

		+ Delete
		
	Cart:

		- ID -> int -> auto generated
		- CustomerId -> int
		- CartStatus -> enum {Active- Checkout}
		- CreatedAt -> Date
		- UpdatedAt -> Date

		+ AddItem
		+ RemoveItem
		+ UpdateQuantity
		+ Checkout

	CartItem:

		- Id -> int -> auto generated
		- CartId -> int
		- ProductId -> int
		- Quantity -> int
		- UnitPrice -> decimal
		
		
	Order:
	
		- ID -> int -> auto generated

		- OrderDate -> Date
		- TotalAmount -> int

		+ Cancel
